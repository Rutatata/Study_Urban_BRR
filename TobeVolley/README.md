# TOBE VOLLEY (飛べ!) — аниме-волейбол с матчмейкингом, как Rematch

PC-игра на Unity 6 (URP): 3D, камера от третьего лица, ты управляешь **одним** игроком,
онлайн-матчи 3×3 и 6×6 через матчмейкинг. Пустые места занимают боты, а если кто-то зашёл
в матч, который уже идёт, он занимает место бота (как в Rematch). Можно играть офлайн с ботами.

## Как открыть
1. Установи **Unity 6000.0 LTS** (любой 6000.0.x) через Unity Hub с модулем *Windows Build Support*.
2. Unity Hub → *Add project from disk* → папка `TobeVolley`. Hub может предложить версию редактора: соглашайся на свою 6000.0.x.
3. При первом открытии Unity скачает пакеты: URP, Netcode for GameObjects, Multiplayer Services,
   Input System и UniVRM (с GitHub). Затем скрипт `Tobe/Setup Project` сам создаст URP-ассет,
   сцену `Assets/_Tobe/Scenes/Main.unity`, Build Settings и Player Settings.
   Если Unity попросит перезапуск из-за Input System, соглашайся.
4. Открой сцену `Main` и нажми **Play** → **ТРЕНИРОВКА С БОТАМИ**. Работает без интернета и без аккаунтов.

## Онлайн (матчмейкинг)
Онлайн работает на бесплатном тарифе Unity Gaming Services: сессии плюс Relay, без своего сервера (хостит один из игроков).
1. *Edit → Project Settings → Services*: войди в Unity-аккаунт и привяжи проект (*Link / Create project ID*).
2. В https://cloud.unity.com открой проект и включи **Relay** и **Lobby** (Multiplayer → Sessions).
3. В игре: **НАЙТИ МАТЧ** подключает к открытой сессии 3×3 или 6×6 либо создаёт новую. Через 25 секунд
   ожидания (или по кнопке «Начать сейчас») пустые места займут боты.
   **ПРИВАТНЫЙ МАТЧ** выдаёт код, друзья входят через **ВОЙТИ ПО КОДУ**.
4. Проверка на одном ПК: *File → Build And Run*, а второй клиент запусти в редакторе
   (или поставь пакет *Multiplayer Play Mode*).

## Управление
| Клавиша | Действие |
|---|---|
| WASD | бег (относительно камеры) |
| Shift | рывок |
| Мышь | камера и прицел (точка на полу, куда полетит мяч) |
| ЛКМ | касание: приём, пас (в сторону прицела), удар в прыжке; на подаче: держи для силы |
| Пробел / ПКМ | прыжок: атака или блок у сетки |
| E | нырок |
| C | «Дай мне!»: связующий даст пас тебе |
| Q | зарядить добивание (при полной энергии) |
| Esc | меню |

## Как устроен матч
- Правила волейбола: 3 касания, двойное касание, аут, сетка, блок (не считается касанием), эйс, переход подачи, партия до 15 с разницей в 2.
- **Стили игрока** (вместо фиксированных героев, как в Rematch): Связующий, Доигровщик, Центральный, Диагональный, Либеро.
  У каждого свои характеристики и **добивание**: «Пас-гильотина», «Удар аса», «Странная быстрая», «Левая пушка», «Роллинг Сандер».
- Добивание: катсцена, замедление, кинематографичная камера, трещины на полу, ударная волна.
- Удар точно в высшей точке прыжка даёт «ИДЕАЛЬНО!» и усиленный удар.

## Архитектура (`Assets/_Tobe/Scripts`)
| Папка | Что внутри |
|---|---|
| `Shared/Contracts.cs` | общие типы: состояние матча, события, стили, `GameHub`, `NetApi` |
| `Sim/VolleySim.cs` | серверная симуляция: мяч, правила, ИИ ботов, касания живых игроков |
| `Net/` | `NetSession` (UGS-сессии, Relay, офлайн-хост), `MatchServer` (лобби, боты, тик 60 Гц, снапшоты 30 Гц), `MatchClient` (приём состояния, локальное движение, отправка ввода), `NetProto` (бинарный протокол поверх NGO named messages) |
| `View/` | арена, персонажи VRM с процедурной анимацией, мяч, эффекты, камера |
| `UI/` | меню, персонаж, лобби, HUD, катсцены, пауза, итоги, звук |
| `Core/GameBootstrap.cs` | собирает всю игру из кода при запуске любой сцены |
| `Editor/TobeSetup.cs` | автонастройка проекта |

Сеть: сервер (хост) авторитетен по мячу, правилам и ботам. Движение своего игрока считает клиент,
поэтому управление отзывчивое; сервер проверяет его по скорости и границам.
Сообщения идут через `CustomMessagingManager` из NGO, поэтому сетевые префабы не нужны.

## Ассеты
Аниме-модели в `Assets/StreamingAssets/Characters/*.vrm` грузятся во время игры через UniVRM (шейдер MToon).
Чтобы добавить свои модели (например, из VRoid Studio), положи в эту папку `.vrm` файлы: они появятся в выборе персонажа.
Лицензии и авторы перечислены в `Assets/_Tobe/ASSET_CREDITS.md`.

## Статус
Это первая играбельная сборка (vertical slice). Код писался без запуска Unity и проверен только
компиляцией против эталонных сборок Unity, поэтому при первом открытии возможны мелкие ошибки компиляции или
визуальные огрехи. Пришли текст ошибки из Console, и я поправлю.
Анимации процедурные, без мокапа. Следующий шаг по качеству — mocap-анимации (например, Mixamo) и свои модели.
